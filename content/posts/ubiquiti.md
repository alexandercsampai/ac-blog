Recently bought an Ubiquiti Cloud Gateway Ultra, If you have read my Internet issues blog post you may know why.
At 115EUR its a good entry way into ubiquiti hardware, even on online shop Alza.sk it's the number 1. selling ubiquiti gateway. 
The initial setup is easy - if you have internet - which i didnt have because of the afformentioned internet issues.. an ofline way to set it up locally would be nice because i 
had to connect to internet to finish of initial setup. I do understand for security It's important to be online but regardless it was an issue
  
Wile setting up I got even MAC address clone option, I like this because i dont have to talk to my ISP to set this gateway up. The UI is nice, simple, I felt like I'm familiar with it 
and didnt have to search much to find all the settings I wanted to set. Kinda this should be the goal of any UI, sadly most companies fail at delivering at this.
  
After setup internet was working fine but the next day i got again internet outages, kinda outrageus since We just switched to a different router but oh well I'm gonna look into it.
I enabled DNS over HTTPS and set some specifc for IDS/IPS. While this at that moment didn't solve the Internet, the days following I encountered 0 outages.
It seems like it may have been the ISP's DNS all along. 
I will see about a week for now if the internet outages start again. If they do I will really be out of options, but currently it seems like this should be fine for long term
  
Anyways thank you for reading my blog! 
Have an amazing day!
