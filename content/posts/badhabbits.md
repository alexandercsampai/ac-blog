While many solutions do exists I would like to point out one specific project that I tried and they are kinda nice
It's called Beeper. a very simple app that is built around idea of having one single chat app for all messages
while its made for multi app messaging combination there are some nice features that actually make it amazing at removing algortihms. You can chat normally with everyone with everyone you already chatted with. if they 
send videos you can watch it, reply etc.. almost all main features work, you can even search for people to add
them tho this can be hit or miss. Currently supports Instagram, Facebook, Discord, Telegram, Twitter, Slack, 
Linkedin, Google messages, Signal, Google chat, Line, Google Voice, Tumblr, Viber, Wechat, CHatgpt Dots, Grok 
Bot. For their backend they use Matrix so you can chat with matrix users too! 
There are some ways to add multiple accounts per chat network too by self hosting their bridges:3(+ 
you can also add IRC apparently but am not sure how well it works)
Only unfurtunate thing about beeper that its propietary - but has clients on all major platforms!(linux too hihi)
