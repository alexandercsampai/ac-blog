Recently there's a boom of reverse engineering projects working on getting propietary systems open.
You may have heard the project AnyPS5, for those who don't know It's an translation project of getting every function of PS5 working on Linux and Windwos.
This was super hard before AI came. ReactOS - A Windows reverse engineering project has been in progress for more than two decades and still ain't at 1.0 yet.
AnyPS5 is a much newer project and it has made much higher progress on getting an even more closed system reverse engineered. Currently all GPU shader instructions are translated,
but system library functions are still a lot that needs to be worked on. Still an amazing achievement to do all this in such short amount of time.
Obviously they're not doing this with hand - they're using AI to reverse engineer the systems and make translation code for it. 
  
But AnyPS5 is just a single project, many more are popping up that clone a propietary system and build an AI version of it - for free often
The code they make is all open source, this is happening to every major propietary software like Word, Excel, Adobe photoshop, Solidworks. 
They're not perfect or rather usable currently. But they show an interesting future when any propietary system can be cloned and made free on internet.
Kinda what the AI learned on in first place - free code on internet, but now its giving back to people, eventually we could have major good alternatives to huge propietary programs like
like solidworks on linux that are made to be exact clone, thus skipping the huge licensing costs.
  
It can be really scary for any of these tech giants working on these programs, their main product is being stolen, made free on internet so anyone can use it. 
Personally I believe this is the future that will come out of this era. More open source software, less propietary systems, less of the old licensing costs and platform lockins.
Maybe there's a good path around the AI that is happening in the world, just if there would be less of all the horrbile AI images and videos we would actually be in paradise today.
